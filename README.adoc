The *Coherence Spring* project provides bootstrapping support of https://coherence.community/[Oracle Coherence] for
https://spring.io/projects/spring-framework[Spring Framework] and https://spring.io/projects/spring-boot[Spring Boot].
Coherence Spring also provides a set of components to aid in the integration of Oracle Coherence and various other projects of the Spring ecosystem:

- Spring Data
- Spring's Cache Abstraction
- Spring Session

Furthermore, the project also provides various examples to show-case the integration of Oracle Coherence into Spring-based
projects.

Coherence CE `26.04` is the default runtime dependency for Coherence Spring `{main-release-version}` on Java 17 and
Java 21. Coherence Spring targets Java 17 bytecode. Earlier full-reactor and packaged-consumer checks passed with
CE `26.04` on both JDKs. Final release-artifact qualification remains a separate step.

The additional hardened CI lane selects released CE `26.10` on Java 21. CE `26.10` requires Java 21 or later.
It enables hardened mode by default; applications do not need an explicit mode property. See the reference guide's
link:coherence-spring-docs/src/main/asciidoc/overview.adoc#compatibility[compatibility section] for the test scope.

NOTE: Coherence Spring `5.x` supports commercial Oracle Coherence `15.1.1.0` on Java 17/21 and `26.1.0.0` on Java 21.
See the reference guide's compatibility section linked above for the exact Grid Edition base builds, expected skips
and local qualification limits. Local qualification does not establish Oracle product certification.
The commercial editions listed for `3.x` retain that line's existing compatibility guidance.

Coherence Spring `4.x` supports commercial `15.1.1.0` on Java 17/21 without an additional security-mode setting.
Commercial `26.1.0.0` is supported on Java 21 with explicit `-Dcoherence.security.mode=compatibility` in every
application, client and server JVM before Coherence initializes. Its hardened default does not work unchanged with
the `4.x` integration graph. See the reference guide's
link:coherence-spring-docs/src/main/asciidoc/overview.adoc#compatibility-4[4.x commercial compatibility section]
for the tested source revision, builds and scope.

Development for Coherence Spring 5.x takes place on `main`. The `4.x` and `3.x` branches maintain the older release lines.
The planned tag for Coherence Spring `{main-release-version}` is `v{main-release-version}`.

Applications moving from Coherence Spring 4.x should follow the
link:coherence-spring-docs/src/main/asciidoc/upgrade-5.adoc[Coherence Spring 5.x upgrade guide]. It covers the Spring 7
and Boot 4 baselines, Boot's modular dependencies, optional integrations, source-level changes, and validation steps.

== Building from Source

=== Requirements

In order to build Coherence Spring, you need to have installed:

- https://www.oracle.com/java/technologies/downloads/#java17[Java 17] (Java 21 is fine)
- https://help.github.com/set-up-git-redirect[Git]

=== Check out sources

Check out the development source from the `main` branch using https://git-scm.com/[Git]:

[source,bash,indent=0]
----
git clone https://github.com/coherence-community/coherence-spring.git
cd coherence-spring
git switch main
----

Coherence Spring uses https://maven.apache.org/[Apache Maven] as build tool. You do not need to have Maven installed to
build the project. Simply use the provided https://github.com/takari/maven-wrapper[Maven Wrapper], e.g.:

- *Windows:* `mvnw.cmd clean package`
- *Linux/Mac:* `./mvnw clean package`

=== Build the entire project

Build the entire project using https://maven.apache.org/[Maven]:

[source,bash]
----
./mvnw clean package
----

==== Offline Builds

In case you are offline and you run into issues building the project, e.g.
the Coherence cluster as part of JUnit tests does not start up successfully, then
you may have to provide additional command line arguments:

[source,bash]
----
./mvnw clean package -DargLine="-Dcoherence.localhost=127.0.0.1 -Djava.net.preferIPv4Stack=true"
----

=== Build the Documentation

[source,bash]
----
./mvnw clean package -pl coherence-spring-docs
----

=== Build the project website

[source,bash]
----
./mvnw clean install -pl coherence-spring-site
----

=== Deploy the project website

[source,bash]
----
./mvnw deploy -pl coherence-spring-site
----
