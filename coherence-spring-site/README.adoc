= Coherence Spring Project Website

// DO NOT remove this header - it might look like a duplicate of the header above, but
// both serve a purpose, and the docs will look wrong if it is removed.

The `coherence-spring-site` module builds the Coherence Spring project website and packages the reference documentation
produced by the `coherence-spring-docs` module. Both modules are part of the root Maven reactor.

== Build the Website and Reference Documentation

Run the following command from the repository root:

[source,shell]
----
./mvnw -B -pl coherence-spring-site -am clean package
----

The build creates the website under `coherence-spring-site/target/site/`. It also creates multi-page HTML, single-page
HTML, PDF, and the documentation ZIP under `coherence-spring-docs/target/`, plus aggregate Javadoc under
`target/reports/apidocs/`. The website copies the reference artifacts under `coherence-spring-site/target/site/refdocs/`.

To preview the generated website locally with Python 3, run:

[source,shell]
----
python3 -m http.server 8080 --directory coherence-spring-site/target/site
----

Then open http://localhost:8080/ in a browser.

== Version Attributes

Website AsciiDoc attributes are configured in `coherence-spring-site/sitegen.yaml`. Maven filters expressions such as
`${project.version}` and `${coherence.docs.version}` before Sitegen renders the pages. The current configuration exposes,
among others:

[source,yaml]
----
engine:
  asciidoctor:
    attributes:
      coherence-maven-group-id: "${coherence.groupId}"
      version-coherence-maven: "${coherence.version}"
      version-coherence-spring: "${project.version}"
      version-coherence: "${coherence.docs.version}"
----

Use an attribute in a website `.adoc` file by enclosing its name in braces. For example,
`{version-coherence-spring}` renders the current Coherence Spring project version. Coherence Spring 5.x supports
Coherence CE 26.04; the website no longer defines a commercial Coherence attribute for this baseline.
