= Spring Boot

== Spring Boot

The Spring Boot module of the Coherence Spring project builds upon the core Spring module and enhances it by providing
dedicated auto-configuration support for Spring Boot as well support for Spring Boot configuration properties,
and support for Spring Boot's new ConfigData API to use Coherence as a source of configuration data.

Getting your first Coherence powered Spring Boot application off the ground could not be easier. Create a basic Spring
Boot app using https://start.spring.io/[start.spring.io].

Add the Coherence Spring Boot Starter to your generated app's `pom.xml`:

.Maven
[source,xml,indent=0,subs="verbatim,quotes,attributes"]
----
<dependencies>
    <dependency>
        <groupId>com.oracle.coherence.spring</groupId>
        <artifactId>coherence-spring-boot-starter</artifactId>
        <version>{version-coherence-spring}</version>
    </dependency>
    <dependency>
        <groupId>com.oracle.coherence.ce</groupId>
        <artifactId>coherence</artifactId>
        <version>{version-coherence-maven}</version>
    </dependency>
</dependencies>
----

Coherence Spring {version-coherence-spring} uses Spring Framework 7 and Spring Boot 4. Its supported default is
Coherence CE {version-coherence-maven} on Java 17 or Java 21. Coherence Spring targets Java 17 bytecode.
Coherence Spring 5.x supports commercial Oracle Coherence 15.1.1.0 on Java 17/21 and 26.1.0.0 on Java 21. See the
link:refdocs/reference/html/overview.html#compatibility[compatibility section] for exact builds, expected skips,
test limits and CE 26.10/Java 21 runtime requirements.

The 4.x maintenance line supports commercial 15.1.1.0 on Java 17/21 and 26.1.0.0 on Java 21. For 4.x with 26.1.0.0,
set `-Dcoherence.security.mode=compatibility` in every application, client and server JVM before Coherence initializes.
See link:refdocs/reference/html/overview.html#compatibility-4[4.x commercial runtimes] for the tested revision and limits.

If you are moving an existing application from Coherence Spring 4.x, follow the
link:refdocs/reference/html/upgrade-5.html[Coherence Spring 5.x upgrade guide] before changing dependencies.

This will be enough to start up a default instance of Coherence with default settings. E.g., inject Coherence beans into
your Spring Controllers, Services and other components:

[source,java]
----
@CoherenceCache("myCacheName")
private NamedCache<Long, String> namedCache;
----

In order to dive deeper, please see the link:refdocs/reference/html/quickstart.html[Quickstart Guide], the
https://github.com/coherence-community/todo-list-example/tree/main/java/spring-server[To-do List Sample], and also
refer to the link:refdocs/reference/html/index.html[reference guide].
