== Change History

The following sections outline Coherence Spring project changes in
reverse chronological order.

=== Version 5.0.0

Changes since https://github.com/coherence-community/coherence-spring/releases/tag/v4.3.1[Version 4.3.1]:

*Baseline and integration changes*

* Moves to Spring Framework 7, Spring Boot 4, Spring Data 2025.1, Spring Cloud 2025.1,
  Spring Session 4, Spring Security 7, and Jakarta EE 11. Samples use Jackson 3.
  Java 17 remains the minimum. The default Coherence CE dependency is 26.04.
* Adds `coherence-spring-session-boot-starter` for Boot servlet applications, including WAR deployments.
  The general `coherence-spring-boot-starter` now makes `coherence-spring-session` and `spring-boot-session`
  optional. Use the dedicated starter or declare all three integration artifacts explicitly.
  Applications must also supply a Coherence runtime and servlet web dependencies.
* Updates metrics integration for Boot 4. Add `coherence-micrometer` and provide a `MeterRegistry` bean.
  Use `spring-boot-starter-actuator` or `spring-boot-starter-micrometer-metrics` to create a Boot-managed
  registry, or supply your own. The general Coherence starter plus `coherence-micrometer` alone does
  not create a registry or bind Coherence metrics.
* Updates samples to `resilience4j-spring-boot4` and the Hibernate 7 adapter, `coherence-hibernate-cache-7`,
  from Coherence Hibernate 4.1.0. Applications using that adapter must select a compatible Hibernate ORM
  7.4.x version explicitly. Boot's managed ORM version does not meet that requirement.

*Fixes and behavior changes*

* Fixes Boot Session timeout configuration for external WAR deployments. Set `spring.session.timeout`
  for these deployments; `server.servlet.session.timeout` is not a fallback. Without a configured timeout,
  the repository retains its 30-minute default. Embedded applications retain the server-property fallback.
* Fixes POF serialization of `UsernamePasswordAuthenticationToken` with erased credentials or mixed
  authority types. Preserves authentication state and adds a serializer for Spring Security 7 factor
  authorities that preserves their issuance time.
* Replaces the session-reset lambda with `SessionResetEntryProcessor`. Adds explicit serialization and
  execution permissions for Session library operations on hardened Coherence runtimes.
* Enables Java parameter-name metadata for Spring named-argument resolution.
* Fixes Cloud Config sample JSON responses by copying lazy entity collections before response serialization.
  Replaces the sample's machine-specific Config Server Git path with `CONFIG_SERVER_GIT_URI`.
* Fixes website resources and upgrade-guide links for sites served under version directories.

*Known limitations and migration requirements*

* POF session deployments need new registrations when they reset active sessions (`SessionResetEntryProcessor`)
  or store Spring Security 7 factor authorities (`FactorGrantedAuthorityPofSerializer`).
  Deploy the required classes and mappings to each relevant application and server endpoint.
  Hardened runtimes also need application-owned permissions for session attributes, principals, and authentication details.
* Mixed Coherence Spring 4.x/5.x access to a session cache and rollback after 5.x writes remain unqualified.
  Automatic Session integration supports servlet applications; it does not provide reactive WebSession support.
* The hardening CI lane selects released Coherence 26.10 on Java 21. This configuration does not establish
  completed runtime qualification. Earlier snapshot results do not qualify the release artifacts.
* Commercial Oracle Coherence 15.1.1.0.0 on Java 17/21 and 26.1.0.0.0 on Java 21 passed local qualification.
  Coherence Spring 5.x supports commercial versions 15.1.1.0 and 26.1.0.0 on those JDKs; see the
  link:refdocs/reference/html/overview.html#compatibility[compatibility section] for exact builds, expected skips and test limits.
* Documents commercial support for the 4.x maintenance line: 15.1.1.0 on Java 17/21 and 26.1.0.0 on Java 21.
  The 4.x/26.1.0.0 combination requires explicit `-Dcoherence.security.mode=compatibility` in every application,
  client and server JVM before Coherence initializes; the unchanged 4.x integration graph fails with the hardened default.
  See link:refdocs/reference/html/overview.html#compatibility-4[4.x commercial runtimes] for the tested revision and scope.

See the link:refdocs/reference/html/upgrade-5.html[Coherence Spring 4.x to 5.x upgrade guide]
for dependency examples, POF configuration, session cut-over guidance, and application validation steps.

=== Version 3.0.0.M1 (May 2021)

*Source and Documentation Contributors*

* Gunnar Hillert
* Ryan Lubke

*Changes*

* Change Licensing to UPL (https://www.apache.org/legal/resolved.html[Apache license compatible])
* Completely refactor bootstrapping mechanism using the new Coherence
https://coherence.community/21.06-M1/docs/#/docs/core/02_bootstrap[Bootstrap API] (Community Edition 20.12)
* Add support for Spring Data repositories using the brand-new Coherence
https://coherence.community/21.06-M2/docs/#/docs/core/05_repository[Repository API] which has been introduced with
https://medium.com/oracle-coherence/coherence-ce-21-06-milestone-2-released-4467cc94f118[Coherence CE 21.06 M2]
* Add Spring Cache abstraction support
* Add Spring Boot Starter
  - Provide AutoConfiguration support
  - Add initial support for Spring Boot configuration properties
* Add support for Coherence Event Listeners
* Add initial support for Spring Boot `2.4+` Config API for importing additional configuration data using Coherence as a store
of configuration data
* Add Dependency Injection (DI) support for various Coherence types:
  - Coherence Filters
  - Views
  - Coherence Sessions
* Inject Coherence Maps and Caches:
  - @CoherenceCache
  - @CoherenceMap
  - @CoherenceAsyncCache
  - @CoherenceAsyncMap
* Add support for Filter Binding Annotations
* Add support for Extractor Binding Annotations
* Add https://asciidoctor.org/docs/asciidoc-writers-guide/[AsciiDoc-based] documentation (HTML + PDF)
* Convert the Coherence Spring website to the Coherence CE theme
* Add security vulnerability scans using the https://github.com/jeremylong/DependencyCheck[OWASP Dependency-Check Plugin]
* Provide source-code consistency using the https://github.com/spring-io/spring-javaformat[Spring Java Format Maven Plugin]
* Add Quickstart Sample (Classic Spring + Spring Boot) and reference guide chapter
* Add Spring Cloud Config demo
* Add CI workflow using GitHub Actions
* Add Coherence https://github.com/coherence-community/todo-list-example/tree/main/java/spring-server[To Do List Example Application]
for Spring Boot (separate repository)
* Update to the latest dependencies
  - Oracle Coherence `21.06-M2`
  - Spring Boot `2.4.5`
  - Spring Framework `5.3.5`
